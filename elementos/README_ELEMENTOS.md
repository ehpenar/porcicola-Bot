# Elementos — documentación de proceso Porcicola

| Archivo | Para qué |
|---------|----------|
| `DiagramaConceptualPorcicola.json` | Diagrama draw.io original |
| `Captura de pantalla 2026-11-21...png` | Captura visual del diagrama |
| `ANALISIS_PROCESO_SISTEMA.md` | Análisis inicial del diagrama (crítica + propuesta) |
| `PROCESO_ESTADOS_Y_VISTAS.md` | Contrato técnico de estados/permisos (versión análisis) |
| **`PROCESO_ROBUSTO_PLATAFORMA.md`** | **Proceso oficial propuesto** a partir de la descripción verbal del equipo |
| **`PROMPT_LOVABLE_PLATAFORMA.md`** | Prompt inicial para Lovable (app web 4 perfiles) |
| **`AUDITORIA_LOVABLE_PIXEL_PERFECT.md`** | Revisión del repo GitHub: qué quedó bueno / qué falta |
| **`PROMPT_LOVABLE_CONTINUAR.md`** | Prompt para retomar en Lovable (solo cablear pantallas) |

## Orden de lectura recomendado

1. `PROCESO_ROBUSTO_PLATAFORMA.md` — cómo debe funcionar la plataforma  
2. `AUDITORIA_LOVABLE_PIXEL_PERFECT.md` — estado actual del código Lovable  
3. `PROMPT_LOVABLE_CONTINUAR.md` — completar pantallas cuando haya créditos  
4. `PROMPT_LOVABLE_PLATAFORMA.md` — prompt original  
5. `PROCESO_ESTADOS_Y_VISTAS.md` / `ANALISIS_PROCESO_SISTEMA.md` — contexto
